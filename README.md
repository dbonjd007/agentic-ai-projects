# 🤖 Agentic AI & Autonomous LLM Systems

A curated collection of multi-agent architectures, function-calling workflows, and high-throughput inference implementations using open-source Large Language Models (LLMs) and Groq LPU hardware acceleration.

---

## 🚀 Key Features & Architecture Highlights

* **Multi-Agent Systems:** Autonomous multi-agent workflows utilizing goal decomposition, tool-use execution, and automated decision loops.
* **Groq LPU Acceleration:** High-speed inference optimization leveraging Groq API endpoints for sub-second LLM execution.
* **Structured Output & Function Calling:** Function-calling workflows and JSON schema outputs for robust tool integration.

---

## 🛠️ Technical Stack

* **Frameworks & APIs:** Groq API, LangChain, LlamaIndex, OpenAI API
* **Core Language:** Python 3.10+
* **Environment:** Google Colab / Jupyter Notebooks
